Lesson 10 — Unhandled Exceptions  (documented-only)

Owner   : team member responsible for lessons 3–6 / 8 / 10.
Target  : DVSA-ORDER-BILLING / order_billing.py.
Primitive: event["orderId"] on line ~34 is accessed without validation.
           A request missing that field throws KeyError and the full
           Python traceback (including /var/task/order_billing.py +
           line numbers) is returned to the caller, leaking internal
           code structure for reconnaissance.
Fix     : validate input with a schema (pydantic / jsonschema);
          wrap the handler in try/except Exception returning a generic
          {"error":"bad request"}; configure API Gateway to map Lambda
          errors to a generic 500 response.
