Lesson 9 — Vulnerable & Outdated Components

Target  : The Lambda's package.json pins node-serialize@0.0.4, which
          carries CVE-2017-5941 (same RCE surface as Lesson 1, just
          framed as a supply-chain issue).
Primitive: any input that contains _$$ND_FUNC$$_ and reaches
           unserialize() becomes arbitrary code execution.
Proof   : npm audit flags the critical advisory; our exploit
          reproduces the same /tmp/pwned.txt artefact as Lesson 1;
          after removing the dependency, npm audit is clean.
