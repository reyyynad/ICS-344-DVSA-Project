Lesson 5 — Broken Access Control  (documented-only)

Owner   : team member responsible for lessons 3–6 / 8 / 10.
Target  : DVSA-ADMIN-UPDATE-ORDERS Lambda.
Primitive: handler base64-decodes the JWT, reads only "username", never
           checks cognito:groups. Any authenticated user who invokes
           this Lambda directly (e.g. via aws lambda invoke) is treated
           as admin and can flip their own order to status:120 (paid).
Fix     : verify the JWT signature (Lesson 2 fix) AND assert
          cognito:groups contains "admin"; add an API Gateway authorizer
          that rejects non-admin callers.
