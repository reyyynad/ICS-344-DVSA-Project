Lesson 6 — Denial of Service  (documented-only)

Owner   : team member responsible for lessons 3–6 / 8 / 10.
Target  : API Gateway stage → DVSA-ORDER-MANAGER.
Primitive: default stage throttle (~10,000 rps burst) + no per-user /
           per-IP limits. 800 concurrent PowerShell jobs POSTing to
           the billing endpoint saturate Lambda concurrency and throttle
           legitimate users out.
Fix     : set a conservative stage-level throttle (e.g. rateLimit=10,
          burstLimit=20); add a per-API-key usage plan; turn on an AWS
          WAF rate-based rule; alarm on Throttles / ConcurrentExecutions.
