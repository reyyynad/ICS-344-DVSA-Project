Lesson 4 — Insecure Cloud Configuration  (documented-only)

Owner   : team member responsible for lessons 3–6 / 8 / 10.
Target  : dvsa-receipts-bucket-* S3 + DVSA-ADMIN-SHELL Lambda (admin_shell.js).
Primitive: bucket has "Block Public Access" disabled and no deny-default
           bucket policy; the Lambda builds
               const filename = "/tmp/" + body.file;
           so a body like {"file":"../../etc/passwd"} reads arbitrary
           files from the Lambda execution env. The same handler also
           has eval(body.cmd) → direct RCE.
Fix     : turn on all four Block-Public-Access sub-settings; attach a
          deny-by-default bucket policy; replace string concatenation
          with path.basename() + allowlist; remove eval(cmd).
