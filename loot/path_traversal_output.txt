====================================

Payload: {"body": {"userId": "e05ca99c-[REDACTED]", "file": "../../etc/passwd"}}

Confirmed: Path traversal escaped /tmp/ and read /etc/passwd from the
Lambda execution environment. The vulnerable line in admin_shell.js:

  const filename = "/tmp/" + body.file; // VULNERABLE

processed "../../etc/passwd" as-is, resolving to /etc/passwd.
No input validation was present before constructing the file path.
