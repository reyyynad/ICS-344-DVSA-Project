Attack Path:

  2. node-serialize.unserialize() executed attacker JavaScript
  3. Injected code invoked DVSA-ADMIN-UPDATE-ORDERS directly

  4. Admin function set order status=120 (paid) and total=0

Impact:

  $35 order marked as paid without any payment processed.
  Token FREE_RIDE_TOKEN proves no legitimate payment occurred.
