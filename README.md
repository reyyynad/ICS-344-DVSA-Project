# ICS 344 DVSA Project

This repository contains command-driven exploitation scripts for DVSA security labs.

## 🚀 Quick Start

```bash
git clone https://github.com/reyyynad/ICS-344-DVSA-Project.git
cd "ICS 344 DVSA Project"

cp config/example.env config/.env
# Fill in API_URL and JWT_TOKEN

pip install -r requirements.txt

# Run all exploits
./run_all.sh
```

## 📂 Structure

* lessons/ → Exploit scripts per lesson
* loot/ → Extracted data (sanitized)
* mitigations/ → Suggested fixes
